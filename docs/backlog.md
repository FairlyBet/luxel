# Бэклог

Что отложено после ревью (номера — из `docs/review-low.md`, там же исходное описание каждой находки).

## Новые функции (сделать позже)

- **Blend color** (66): константные blend-факторы есть, а задать сам цвет (`blendColor`) нельзя. Нужен параметр в `RenderState` и учёт в кэше состояния.
- **Stencil8** (69): `RenderbufferFormat::Stencil8` есть, но прикрепить его к framebuffer нечем. Нужен `framebuffer_attach_stencil_renderbuffer`.
- **Скорость анимации на модели** (174/175): сейчас скорость живёт на играющем клипе и сбрасывается в 1 при `playAnimation`/`crossfade`. Можно хранить её на `ModelAnimations`, чтобы она переживала смену клипа.
- **Освобождение PBR-вариантов** (251): варианты шейдеров и их depth-only двойники живут до конца сцены. Нужен подсчёт ссылок.
- **`shadowMapSize` у света** (181): геттер возвращает то, что задали, а не реальный размер (степень двойки, лимит устройства).

## Решить

- **Polygon offset под reverse-Z** (67): смещение не переворачивается, хотя рендерер обещает прозрачность reverse-Z для render state. Если починить, у тех, кто подобрал bias под текущее поведение, сдвинутся тени. Решить: чинить (и описать в changelog) или задокументировать как есть.

## Производительность — с замерами на реальном GPU

Делать в локальной сессии с браузером и видеокартой, сравнивая время кадра до и после.

Шейдеры:
- **Подповерхностное рассеяние** (152): 32 вычисления профиля повторяются на каждый свет. Вынос из цикла даёт массив из 32 vec3 на пиксель: на мобильных GPU это может оказаться медленнее из-за давления на регистры. Мерить.
- **GTAO denoise** (150): чтения глубины попадают ровно на угол текселя NEAREST-текстуры; перейти на texelFetch. Нужна визуальная проверка.
- **Полюса запечённого окружения** (147): equirect с мипами пересглаживает полюса; нужен LOD по телесному углу. Визуальная проверка.

CPU, на кадр:
- **Сравнение групп параметров** (78): каждый draw заново сверяет все поля всех групп. Счётчик изменений у группы позволил бы пропускать сверку.
- **pixelStorei** (84): 18 вызовов на каждую загрузку текстуры (сцена грузит инстансы каждый кадр). Отслеживать состояние unpack.
- **Per-target blend** (68): `getExtension` + `Reflect` на каждую смену состояния; закэшировать функции расширения.
- **Имена в горячем пути** (245): `param_set_*_by_name` каждый кадр; закэшировать поля.
- **Uniform-буферы по строке пути** (104): нужен API по `FieldId`.
- **Сигнатуры теней** (226): суставы скина обходятся на каждый примитив и вид.
- **Render state теней** (232): интернируется на каждый вид каждый кадр линейным поиском.
- **Суставы скина** (256): матрицы считаются и пишутся на каждый примитив, а не один раз на скин.
- **Предупреждения на пути draw** (79): строка форматируется на каждый draw, пока условие держится (только в ошибочной конфигурации).

Загрузка и прочее:
- **Async readback** (65): новый GPU-буфер на каждое чтение, двойная копия; нужен пул.
- **Компрессор** (94): синхронные `getTexParameter` после кодирования.
- **VaoBuilder** (108): три копии вершинных данных при сборке.
- **TexturePacker** (137): строится заново на каждую модель.
- **Стадии запекания окружения** (162): стадия — все шесть граней мипа; на больших размерах это рывок в кадре. Разбить по граням.
- **Layout measure** (14): вложенные структуры раскладываются заново при каждом измерении (только при создании).
- **Fallback пуллера** (55): без `setTimeout` раунды идут микрозадачами и не дают GPU-результатам прийти.

## Не локальные исправления

- **Слушатели потери контекста** (31/33): не снимаются; каждый созданный `Context` держит два замыкания. Нужен явный dispose.
- **Компрессор на поток** (91–93): один слот на поток, два контекста вытесняют друг друга.
- **Прекомпиляция 2D BC6H** (90): `whenReady` её не ждёт.
- **Context на чужом GL-контексте** (28): `Context::new` предполагает чистый и единоличный контекст.
- **Fallback-размер канваса** (42): берётся по `clientWidth` (с padding), а не по content box.
- **Размер FBO** (45): метаданные при создании, не сверяются с вложениями.
- **Метки профайлера** (57): переставшие замеряться метки отчитываются вечно.
- **Float-blend guard** (73): пропускает допустимые draw при per-target overrides.
- **Буфер трейса** (98): законченную запись нельзя освободить.
- **Воркеры декодеров** (114): не освобождаются.
- **Проба WebP/AVIF** (120): через `data:` в `<img>`, CSP может её заблокировать.
- **Загрузка картинок модели** (122): уничтожение модели её не останавливает; нужен AbortSignal сквозь загрузчик.
- **despawn и перенесённые узлы** (193): узел модели, перенесённый `setParent` вне её поддерева, остаётся с освобождёнными GPU-данными.
- **Границы скинов для теней** (239): `caster_bounds` схлопывается в точку для кастеров без Bounds и скинов из одного сустава.
- **Повторное запекание при restore** (182): при restore окружение перезапекается, даже если приложение сразу его заменит; байты HDR клонируются.
- **Комментарий про index-буфер** (18): и лишний VAO-unbind при загрузке индексов.
